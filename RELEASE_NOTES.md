# Questionnaire item budgets and AI-service use

Version `v2.0-minor-revision` identifies the public research materials for:

**Questionnaire Item Budgets and Incremental Predictive Value for Self-Reported AI-Enabled Consumer Service Use: Temporal Evidence from a Korean Panel**

Soonho Jang and Eung-Kyo Suh, Dankook University.

The snapshot contains analysis code, aggregate results, software and seed records, figure source data and publication figure exports. The [release manifest](reproducibility/RELEASE.json) maps these materials to their repository paths. GitHub's source archives contain the files at the release's tagged commit.

The materials include aggregate diagnostics of generative-AI experience and its outcome association, within-participant response transitions, overlap between development and evaluation groups, bootstrap software verification, the analysis-specific seed catalogue, and Figure 7 with panel labels (a)–(d). Existing analysis directories are retained so that previously published links and executable relative paths remain usable.

Use the [repository README](README.md) for environment requirements, verification commands, and the order of analysis. Public checks can validate the retained aggregate outputs without respondent-level source data. Full model reconstruction requires authorized KISDI source data under the provider's access conditions.

The release tag is created once for this version. Its exact commit is recorded in the release description. Subsequent research updates should use a new version identifier while preserving this snapshot.
